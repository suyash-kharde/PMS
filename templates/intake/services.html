Switching to the real weights

Both audio services expose OpenAI-compatible routes and start in a fallback engine when the model stack is not installed. Set INSTALL_HUSH=1 and/or INSTALL_NEMO=1 in .env, then rebuild: docker compose build denoise asr && docker compose up -d. Weights are cached in the hfcache volume.
