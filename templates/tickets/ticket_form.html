Changes to an existing UI/page

New UI design or major UI changes

If the request involves creating a new page/screen or significant UI/UX changes, you must first raise a ticket to the UI/UX (Designer) Team. After the design is reviewed and approved, you can proceed with raising the Development Ticket.

Non-UI changes

If the request does not involve any UI changes, you can directly raise the Development Ticket.
