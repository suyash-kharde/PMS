Connect Claude Code to this design

Claude Code reads specs, tickets and the BRD from the Planwise MCP link (Claude Code tab) and builds the UI through Penpot's MCP server. Both are shared services on this server — nothing to install locally — but Penpot's MCP still drives a browser plugin, so a person opens the design file and connects the plugin first.

{% if penpot_mcp_url %}
  1. Add both servers to your .mcp.json (below) and restart Claude Code.
  2. Open the design file in your browser → Plugins → Connect to MCP server.
  3. In Claude Code, keep both connected — planwise for context, penpot for the canvas.

Example .mcp.json:

{
  "mcpServers": {
    "planwise": { "type": "http", "url": "{{ mcp_endpoint }}/<claude-code-token>/" },
    "penpot":   { "type": "http", "url": "{{ penpot_mcp_url }}" }
  }
}
{% else %}

Troubleshooting

If "Open in Penpot" or the invites/share links stop working — usually because the Penpot instance was reset or its objects were deleted — rebuild the workspace. This registers a fresh bot account, team, project and starter file; anything already in the old Penpot file is not carried over.
